# Upload Options

## GitHub (Preferred for PRs)

1. Open the PR or issue.
2. Drag and drop the images into the comment box.
3. Copy the image URLs from the markdown preview.

## Chat Tools (Slack/Discord)

1. Upload the screenshot.
2. Copy the image link.

## Cloud Storage

1. Upload to Drive/Dropbox/OneDrive.
2. Set sharing to anyone with the link.
3. Copy the shareable link.
