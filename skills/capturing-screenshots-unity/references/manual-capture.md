# Manual Capture Options

## Unity Editor

1. Open the affected scene.
2. Enter Play Mode.
3. Navigate to the feature.
4. Capture from Game View (not Scene View).

## Unity Screenshot Tool (if available)

1. Window -> General -> Screenshot Tool.
2. Configure capture settings.
3. Capture from Game View.

## System Shortcuts

- Windows: Win + Shift + S
- Mac: Cmd + Shift + 4
- Linux: PrtScn or system capture tool
